# Testbed — 2021.3 LTS

A Unity project that consumes this repository's package, authored with
**2021.3.45f2**. Open it with a 2021.3 LTS editor.

Everything is already wired: the package as a relative local path, `testables`
for the Test Runner, the `QUICKACTIONS_ENABLED` define, and three static
shortcuts that appear on a long-press before the app is ever opened.

See [`../README.md`](../README.md) for what each piece does, how to run the
74-test suite, and how to build to a device from the command line. The other
editor lines have their own project next door.
