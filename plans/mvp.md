# Quick Actions for Unity — Implementation Plan (MVP / v0.1)

## Context

The paid Unity Asset Store package **"Quick Actions for iOS and Android"**
(`311869`, min Unity `2022.3.43f1`, v1.1.0) lets a Unity game expose
**home-screen quick actions** — the shortcuts that appear when a user
long-presses the app icon. On iOS these are `UIApplicationShortcutItem`s; on
Android they are App Shortcuts driven by `ShortcutManager` / `shortcuts.xml`.

This project is a clean-room, MIT-licensed re-implementation targeting
**Unity 2022 LTS and newer** (incl. Unity 6). It must:

- Let developers declare **static** shortcuts in the Editor (baked into the
  build) and create/replace **dynamic** shortcuts at runtime.
- Fire a **callback** in C# with the action id when the app is launched or
  resumed from a quick action (cold start *and* warm resume).
- Require **zero manual native edits** — Info.plist / AndroidManifest /
  `shortcuts.xml` are patched automatically by build post-processors.
- Work across the 2022→6 Unity span where the Android entry point changed
  from `UnityPlayerActivity` to `UnityPlayerGameActivity`.

## Design decisions

| Decision | Choice | Why |
|---|---|---|
| Distribution | UPM package (`package.json` at project root) | Installable by Git URL / local path; clean asmdef isolation; `Samples~` import. |
| Public API | One static facade `QuickActions` + `QuickAction` POCO | Mirrors the asset's simple surface; easy to script. |
| iOS native hook | **Method swizzling** of `UnityAppController` in an Obj-C category `+load` | True plug & play — no editing Unity's generated `main`/AppDelegate. |
| Android entry hook | **Trampoline activity** (`QuickActionsTrampolineActivity`) + poll-on-focus | Avoids subclassing Unity's activity, so it works on both `UnityPlayerActivity` (2022) and `UnityPlayerGameActivity` (6+). |
| Cold-start delivery | Native buffers a "launch action id"; C# pulls it on startup | Native fires before C# subscribers exist; pull avoids a lost event. |
| Warm delivery | iOS `performActionForShortcutItem` → `UnitySendMessage`; Android `OnApplicationFocus` poll | Standard live-app path on each platform. |
| Serialization | `JsonUtility` + list wrapper | No extra deps; native parses with `NSJSONSerialization` / `org.json`. |

## Public API (final shape)

```csharp
namespace Playground.QuickActions {
  public static class QuickActions {
    public static bool IsSupported { get; }
    public static event Action<string> ShortcutTriggered;     // action id
    public static void SetDynamicShortcuts(IList<QuickAction> actions);
    public static void AddDynamicShortcut(QuickAction action);
    public static void RemoveDynamicShortcut(string id);
    public static void ClearDynamicShortcuts();
    public static string ConsumeLaunchShortcutId();            // id app cold-launched with, else null
  }
  [Serializable] public class QuickAction {
    public string Id, Title, Subtitle, Icon;   // Icon: iOS UIApplicationShortcutIconType name OR Android drawable name
  }
}
```

## Native contracts

**iOS** (`QuickActions.mm`, C functions called via `DllImport("__Internal")`):
`_QuickActions_SetDynamicShortcuts(const char* json)`,
`_QuickActions_ClearDynamicShortcuts()`,
`_QuickActions_ConsumeLaunchShortcutId() -> char*`.
A `UnityAppController(QuickActions)` category swizzles
`application:didFinishLaunchingWithOptions:` (capture cold-launch shortcut,
return original result) and installs
`application:performActionForShortcutItem:completionHandler:`
(warm path → `UnitySendMessage("QuickActionsRuntime","OnShortcutTriggered",id)`).

**Android** (`QuickActionsBridge.java`, called via `AndroidJavaClass`):
`setDynamicShortcuts(Activity, String json)`, `clearDynamicShortcuts(Activity)`,
`consumeLaunchShortcutId()`. Dynamic `ShortcutInfo`s target
`QuickActionsTrampolineActivity` with `EXTRA_ACTION_ID`. The trampoline stores
the id in a static + `SharedPreferences`, relaunches the Unity activity, and
finishes; C# reads it via `OnApplicationFocus(true)` poll and on startup.

## Build post-processors

- **iOS** `OnPostprocessBuild` (`IPostprocessBuildWithReport`): read
  `QuickActionsSettings`, write `UIApplicationShortcutItems` into
  `Info.plist` via `PlistDocument`; copy any custom template icons.
- **Android** `IPostGenerateGradleAndroidProject`: emit
  `unityLibrary/src/main/res/xml/quickactions_shortcuts.xml`, add
  `<meta-data android:name="android.app.shortcuts" .../>` to the launcher
  activity and declare `QuickActionsTrampolineActivity` in the merged
  `AndroidManifest.xml`.

## Verification (no Unity in this container — run these in your project)

1. **Compile gate (here):** `tools/check.sh` greps for balanced braces and
   that every `.cs`/`.mm`/`.java` parses with `dotnet`/`clang -fsyntax-only`
   where toolchains exist; otherwise a structural lint. (Best-effort only.)
2. **Import:** add the package via Package Manager → *Add package from disk*
   → `package.json`. Console must be error-free on 2022.3 LTS and Unity 6.
3. **Static shortcuts:** Project Settings → *Quick Actions*, add two actions →
   build to device → long-press icon → both appear.
4. **Dynamic:** import the **Demo** sample, build, tap *Add Shortcut* → new
   action appears on long-press without a rebuild.
5. **Callback:** force-quit, long-press → tap an action → app launches and the
   demo label shows the action id (cold path). Repeat while backgrounded
   (warm path).
6. iOS device test via Xcode (`UIApplicationShortcutItem`), Android via
   `adb shell cmd shortcut` / long-press on API 25+.

## Out of scope (→ ROADMAP)
